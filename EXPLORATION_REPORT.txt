========================================================
1. DATASET OVERVIEW
========================================================

Source: MIT-BIH Arrhythmia Database (PhysioNet)
Version: 1.0.0
Format: WFDB (WaveForm DataBase) - .dat, .hea, .atr files

Main Database:
  - 48 records (100-234, excluding some numbers)
  - Each record: ~30.1 minutes (650,000 samples at 360 Hz)
  - Two leads per record (from MLII, V1, V2, V4, V5)
  - Total duration: ~24.1 hours
  - Total annotated beats: 109,494

Supplementary Database (x_mitdb):
  - 23 records (x_108 through x_234)
  - Each record: ~10 minutes (216,000 samples at 360 Hz)
  - Two leads: MLII + V1
  - Total duration: ~13.8 hours

File Structure:
  *.dat  - Binary signal data (212 format, 16-bit)
  *.hea  - Header file (metadata, lead info)
  *.atr  - Reference annotations (beat + rhythm)
  *.xws  - Waveform server config
  RECORDS - List of record names
  ANNOTATORS - Annotation file descriptions
  SHA256SUMS.txt - Checksums
  mitdbdir/ - Documentation files
  x_mitdb/ - Supplementary records

3. ANNOTATION ANALYSIS
========================================================

Annotation Types Found (all records):
  N  - Normal beat
  L  - Left bundle branch block beat
  R  - Right bundle branch block beat
  e  - Atrial escape beat
  j  - Nodal (junctional) escape beat
  A  - Atrial premature beat
  a  - Aberrated atrial premature beat
  J  - Nodal (junctional) premature beat
  S  - Supraventricular premature beat
  V  - Premature ventricular contraction
  E  - Ventricular escape beat
  F  - Fusion of ventricular and normal beat
  /  - Paced beat
  f  - Fusion of paced and normal beat
  Q  - Unclassifiable beat
  +  - Rhythm change
  ~  - Signal quality change
  |  - Isolated QRS-like artifact
  [  - Start of ventricular flutter/fibrillation
  ]  - End of ventricular flutter/fibrillation
  !  - Ventricular flutter wave
  "  - Non-conducted P-wave
  x  - Non-conducted P-wave (alternative)

AAMI CLASS MAPPING:
  Class N (Normal): N, L, R, e, j
  Class S (SVEB): A, a, J, S
  Class V (VEB): V, E
  Class F (Fusion): F
  Class Q (Unknown): /, f, Q
  Non-beat: +, ~, |, [, ], !, ", x

10. RECOMMENDATIONS FOR MACHINE LEARNING
========================================================

A. Train/Test Split Strategy
   USE RECORD-WISE SPLITS (not beat-wise) to avoid data leakage

   Standard AAMI Split (DS1/DS2):

   DS1 (Training): 101, 106, 108, 109, 112, 114, 115, 116, 118, 119,
                   122, 124, 201, 203, 205, 207, 208, 209, 215, 220,
                   223, 230 (22 records)

   DS2 (Testing): 100, 103, 105, 111, 113, 117, 121, 123, 200, 202,
                  210, 212, 213, 214, 219, 221, 222, 228, 231, 232,
                  233, 234 (22 records)

B. Preprocessing Pipeline
   1. Bandpass filter: 0.5-40 Hz (Butterworth 2nd-4th order)
   2. Normalization: Per-record z-score or global [-1,1]
   3. Beat segmentation: 240ms window centered on R-peak
      (90ms pre-R, 150ms post-R at 360 Hz = 240 samples)
   4. Baseline correction: Remove wander if needed
   5. Quality check: Exclude noisy segments

C. Class Balancing Strategies
   - VEB (7,236): Adequate, consider slight undersampling
   - SVEB (2,781): Deficient - use SMOTE, oversampling, or weighted loss
   - Q/Paced (8,043): Consider excluding or separate class
   - Fusion (803): Very few - may merge or exclude
   - Non-beat: Exclude from beat classification

D. Suggested Class Mapping for 4-Class Problem
   Class 0 (Normal): N, L, R, e, j
   Class 1 (SVEB): A, a, J, S
   Class 2 (VEB): V, E
   Class 3 (Fusion): F
   (Exclude: /, f, Q, +, ~, |, [, ], !, ", x)

E. Model Architecture Considerations
   - Input: Single lead (MLII) or dual lead (MLII + V1)
   - 1D CNN: Effective for raw waveform input
   - RNN/LSTM: Good for temporal dependencies
   - Transformer: State-of-the-art for ECG classification
   - Ensemble: Combine multiple architectures

F. Evaluation Metrics
   - Per-class: Precision, Recall, F1-score
   - Overall: Accuracy, Macro-F1 (important for imbalance)
   - Confusion matrix analysis
   - Per-record performance (clinical relevance)

G. Data Augmentation
   - Time warping
   - Amplitude scaling
   - Gaussian noise addition
   - Random cropping
   - Mixup between same-class beats
